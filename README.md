# Портфолио Frontend-разработчика

Дипломный проект по специальности «Frontend-разработчик» (Университет «Синергия»).
Современный адаптивный сайт-портфолио, созданный для демонстрации навыков веб-разработки, реализованных проектов и контактной информации.

## 🌐 Живая версия
С проектом можно ознакомиться по ссылке: **https://eliseev-ey.ru**

## 🚀 Технологии
В проекте использован современный стек технологий:
*   **React 19 + TypeScript** — основа приложения, строгая типизация.
*   **Vite** — сверхбыстрый сборщик.
*   **Tailwind CSS v4** — стилизация, адаптивность (Mobile-first) и CSS-переменные для тем.
*   **React Router v6** — маршрутизация (SPA).
*   **Framer Motion** — плавные анимации при прокрутке и переходах.
*   **Swiper** — 3D-слайдер проектов на главной странице.
*   **Яндекс Карты API** — интерактивная карта города Абакан.
*   **EmailJS** — отправка писем через форму обратной связи без бэкенда.
*   **GitHub REST API** — автоматическая загрузка последних репозиториев.

## ✨ Основные возможности (Фичи)
*   **Светлая и тёмная темы** (переключение с сохранением выбора).
*   **Полная адаптивность** (десктоп, планшет, смартфон).
*   **Слайдер** лучших работ на главной странице.
*   **Фильтрация проектов** по категориям (Jira Clone, Figma Clone, Лэндинг, API и др.).
*   **Модальные окна** с подробным описанием каждого проекта, стеком и ссылками.
*   **Валидация формы** обратной связи и реальная отправка сообщений на почту.
*   **Динамический таймлайн** образования и опыта.

## 🛠 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/eliseevgeniy/portfolio.git
   ```
2. Перейдите в папку проекта и установите зависимости:
```bash
cd portfolio
npm install
```
3. Создайте файл .env в корне проекта и добавьте ваши ключи (для работы карт и формы):
```env
VITE_YANDEX_MAPS_KEY=ваш_ключ_яндекс_карт
VITE_EMAILJS_SERVICE_ID=ваш_service_id
VITE_EMAILJS_TEMPLATE_ID=ваш_template_id
VITE_EMAILJS_PUBLIC_KEY=ваш_public_key
```
4. Запустите сервер разработки:
```bash
npm run dev
```
## 📦 Сборка проекта
Для создания production-версии (папка dist) выполните:
```bash
npm run build
```
